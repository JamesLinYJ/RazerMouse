# SVG 图标与面板设计

- `app-icon.svg`：1024 × 1024 的原创应用图标；构建时由 AppKit 从 SVG 生成各尺寸 PNG，再由 iconutil 打包 ICNS。
- `../app/Sources/RazerMouse/Resources/ControlIcons.xcassets/`：24 个原创 24 × 24 SVG 控制图标，以及鼠标插画；源文件保留矢量，不依赖字体或远程资源。
- 图标采用 1.65 单位圆端线条。控制图标作为 template 资源适配深浅色；插画保留灰绿与薄荷绿配色。
- SwiftUI 的 `DesignSystem.swift` 集中定义强调色、圆角、图标、卡片标题和按钮选中样式。
- DPI 拖动使用对数映射，让低 DPI 区间仍易操作；范围和离散可选值从 Rust ABI 提供。输入框精确填写，滑杆松开后提交。回报率按钮直接提交；电源控制保留设备范围校验。
- 电源滑杆按原始协议值提交，百分比输入由边界层换算。设备上报超出可写范围的原值仍显示，用户明确调整前不会夹紧后写入。
- 无持续动画，按压反馈遵守系统降低动态效果设置；支持减少透明度。按钮、字段和滑杆带可访问性名称。

预览位于 `../build/screenshots/`，使用 SwiftUI/AppKit 实际视图渲染的模拟设备数据，不是硬件写入验收。正式应用不包含模拟数据。
